# Sumanth Reddy — Portfolio

My personal portfolio website, where I share my work, experience, and writing.

## Pages

- **Home** — introduction and highlights
- **About** — background, technical journey, principles, and skills
- **My Works** — project case studies
- **Testimonials** — feedback from clients and collaborators
- **Blog** — articles on AI, engineering, and building products
- **Contact** — ways to get in touch

## Tech Stack

- Next.js (App Router) and TypeScript
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber
- Nodemailer for email

## Running Locally

```bash
git clone https://github.com/sumanth-com/Sumanth-Folio.git
cd Sumanth-Folio
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

To enable the email features, create a `.env.local` file:

```env
EMAIL_USER=your_email@example.com
EMAIL_PASS=your_app_password
```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm start` — run the production build
- `npm run lint` — run ESLint
